# Sangjin’s Page

Personal academic website of Sangjin Jin, M.S. student at UNIST.

Website: https://jinsaaang.github.io/

## Editing

- `index.html`: profile, research, publications, projects, and honors
- `style.css`: responsive layout and light/dark palettes
- `theme.js`: system theme and saved preferences
- `assets/`: profile photo and locally hosted fonts

No build step or package installation is required. GitHub Pages publishes the root of the `main` branch.

After editing and reviewing the changes:

```sh
git add index.html style.css theme.js assets
git commit -m "Update academic website"
git push origin main
```

## Visitor counts

GoatCounter (`jinsaaang.goatcounter.com`) tracks visits on the production host only. Enable "Allow adding visitor counts on your website" in the GoatCounter site settings and use Asia/Seoul as the reporting timezone. The footer uses the public counter endpoint with a Korean calendar date range for Today and an unbounded range for Total. Both are service-defined visitor counts; they are not a census of distinct people. Counters may be cached for up to four hours. Tracking begins when deployed, without historical backfill. If the public endpoint is disabled, blocked or unavailable, the footer counter stays hidden. No API token is used or exposed.
